# Ejemplos

Este directorio contiene entradas sintéticas y reutilizables. No incluye
papers, abstracts, resultados de revisiones reales ni credenciales.

- `minimal-intake.md` muestra la información mínima para iniciar una revisión.
- `cli-init-example.sh` contiene el equivalente por línea de comandos.
- `review-output-layout.md` explica el árbol de salida esperado sin publicar un
  corpus de terceros.
