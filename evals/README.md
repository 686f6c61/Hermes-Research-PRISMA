# Golden evaluation

This directory contains the human-labelled evaluation contract for Hermes
Research. It is separate from live review workspaces: gold labels must never be
generated by the same model they evaluate.

Each methodological field has an empty starter set under `golden/`. A release
team should populate 40-80 screened records per field, including clear
inclusions, clear exclusions, borderline cases, extraction cells, and
page-located evidence. Use DOI as the study identity.

The deterministic CI fixture under `fixtures/` proves the evaluator itself. It
is synthetic test data and must not be reported as scientific evidence.

Run:

```bash
python3 seed/hermes-home/skills/research/prisma-systematic-review/scripts/evaluate_golden.py \
  evals/fixtures/common \
  evals/fixtures/common/predictions.jsonl \
  --output-dir /tmp/hermes-golden-report
```

Required gold files:

- `gold-records.csv`: the human include/exclude/review decision and reason.
- `gold-extraction.csv`: one approved value per DOI and extraction field.
- `gold-evidence.csv`: one approved page and source fragment per claim.

Generated outputs:

- `metrics.json`
- `evaluation-report.md`
- `error-analysis.csv`
- `screening-confusion-matrix.png`
