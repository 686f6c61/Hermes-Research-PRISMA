# Support

## Usage and installation

Read the [installation guide](docs/installation.md), the
[command reference](docs/commands.md), and the
[troubleshooting guide](docs/troubleshooting.md) first.

If the problem remains, open a GitHub issue using the bug-report form. Include
the package version, operating system, Docker and Compose versions, installation
mode, the command that failed, and a redacted log excerpt.

## What must not be shared

Never attach `.env`, API keys, Telegram tokens, private full-text papers,
personal data, unpublished manuscripts, or an unredacted review workspace.
Replace secrets and local paths before sharing logs.

## Security

Do not report vulnerabilities in a public issue. Follow the private process in
[SECURITY.md](SECURITY.md).

## Research interpretation

Project support can help with reproducibility, execution, and artifact
integrity. It cannot validate a manuscript's scientific claims, replace domain
expertise, or guarantee acceptance by a journal.
