# Revision Roadmap Schema

Use the roadmap as a working matrix between review and implementation.

## Categories

- `argument`
- `method`
- `results`
- `discussion`
- `figures-tables`
- `citations`
- `writing`
- `formatting`
- `ethics`
- `other`

## Priority

- `high`: blocks submission, trust, or reviewer acceptance
- `medium`: materially improves publishability
- `low`: polish, formatting, or local clarity

## Status Lifecycle

- `open`
- `in-progress`
- `done`
- `deferred`
