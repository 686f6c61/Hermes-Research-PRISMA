# Structural analysis

This directory is generated after full-text extraction. It contains an
auditable bibliometric and evidence-network atlas and never changes the
screening decisions.

- `atlas/`: self-contained HTML explorer.
- `data/`: normalized nodes, edges, and GraphML.
- `metrics/`: centrality, communities, production, drift, and summaries.
- `audit/`: coverage, parameters, and provenance.
- `cache/`: reusable external metadata responses.
- `figures/`: optional SVG and PNG exports selected for analytical value.
