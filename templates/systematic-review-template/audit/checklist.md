# Audit Checklist

## Fase 1. Intake y protocolo
- [ ] Tema, años, inclusión, exclusión, autores y modo autónomo completos
- [ ] Pregunta de investigación definida
- [ ] Criterios de elegibilidad definidos
- [ ] Estrategia de búsqueda documentada

## Fase 2. Búsqueda, DOI y deduplicación
- [ ] Log de búsqueda completo y trazable
- [ ] DOI audit ejecutado
- [ ] Duplicados registrados
- [ ] Registros sin DOI marcados para resolución

## Fase 3. Screening
- [ ] Title/abstract screening actualizado
- [ ] Exclusiones con `reason`, `reason_detail` y `exclusion_score`
- [ ] Full-text retrieval documentado
- [ ] Full-text screening actualizado

## Fase 4. Extracción
- [ ] Metadatos bilingües completos cuando existan o puedan traducirse
- [ ] Tipo de trabajo y tipo empírico completados cuando proceda
- [ ] País, muestra, tamaño muestral y método extraídos cuando proceda
- [ ] Variables y marco teórico completados o marcados como no reportados
- [ ] `evidence_snippet`, `evidence_location` y `extraction_confidence` revisados

## Fase 5. Síntesis, estilo y citación
- [ ] Conteos PRISMA consistentes
- [ ] Si hay límite final `N`, shortlist ultraquality generado y documentado
- [ ] Inventario de figuras actualizado
- [ ] SVG renderizados a PNG para el paper
- [ ] Redacción en español de España alineada con RAE
- [ ] Afirmaciones y síntesis referenciadas en APA
- [ ] Decisiones y cambios de modelo documentados

## Auditoría final
- [ ] Auditoría por fase completada
- [ ] Auditoría final completada
- [ ] Export incremental a Obsidian verificado
- [ ] Mensajes de progreso en Telegram enviados por fase
