# Templates

Este directorio contiene la plantilla material que usa el modo research para
crear una revisión nueva sin improvisar estructura.

## Qué contiene

- `systematic-review-template/`

La plantilla incluye:

- protocolo inicial
- estrategia de búsqueda
- carpetas de screening y extracción
- secciones del manuscrito
- base de figuras y tablas
- capa de auditoría y revisión editorial

## Por qué está aquí

El arranque público por Telegram y el wrapper CLI no crean carpetas “a ojo”.
Copian primero esta plantilla al workspace runtime y luego escriben encima los
primeros artefactos del tema concreto.

Eso hace que una instalación nueva conserve la misma forma metodológica desde
el primer día, incluso antes de lanzar la primera revisión real.
